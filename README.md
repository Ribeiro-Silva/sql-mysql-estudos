# sql-mysql-estudos

Exercícios de SQL desenvolvidos com **MySQL** durante meus estudos de banco de dados na graduação em Ciência da Computação (Universidade Cruzeiro do Sul).

O objetivo é praticar modelagem, consultas e manipulação de dados, com foco em organizar, filtrar e validar informações.

## Conceitos praticados
- Criação de bancos e tabelas (`CREATE DATABASE`, `CREATE TABLE`) com chaves primárias e estrangeiras
- Inserção, atualização e exclusão de dados (`INSERT`, `UPDATE`, `DELETE`)
- Consultas com filtros e ordenação (`SELECT`, `WHERE`, `ORDER BY`)
- Junção de tabelas (`INNER JOIN`, `LEFT JOIN`)
- Agregações e agrupamentos (`COUNT`, `SUM`, `AVG`, `GROUP BY`, `HAVING`)
- Subconsultas


## Como executar
1. Instale o [MySQL](https://dev.mysql.com/downloads/) e um cliente, como o MySQL Workbench.
2. Clone o repositório:
   ```
        bash
        git clone https://github.com/Ribeiro-Silva/sql-mysql-estudos.git
   ```
3. Abra o script desejado na pasta `Exercicios/` e execute no seu cliente MySQL.
4. Os dados usados são fictícios, criados apenas para estudo.
